# code_wifi_indoor_localization
Wi-Fi Fingerprinting use for Indoor Localization 


# Project Description 
In our project, we will develop a predictive model to predict a person’s location in a building. Each Wi-Fi access point (WAP) network produces a received signal strength indicator (RSSI) measurement. The pattern of those signal strengths can serve as a fingerprint of a physical location. We will use machine learning approaches: K-Nearest Neighbors (KNN), Random Forest, and Neural Networks and compare their performance in how accurately they predict indoor locations from Wi-Fi fingerprints. We will examine how well each approach handles the variability of indoor Wi-Fi signals, while also investigating which signal features contribute most to prediction accuracy.
